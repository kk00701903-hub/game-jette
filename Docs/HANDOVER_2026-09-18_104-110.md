## 부록 A. 작업 환경 · 파이프라인 · 함정

### A-1. Kling (그림 생성) — 현재 상태
- **API 경로(`kling_*` MCP)는 잔액 0 이라 못 쓴다** — `POST /v1/images/generations` 가 429 `{"code":1102,"message":"Account balance not enough"}`. 또 `kling-v1`·`kling-v1-5`·`kling-v2`·`kling-v2-new` 는 전부 단종, 지금 유효한 이름은 **`kling-v2-1`**(잔액만 있으면 됨).
- 그래서 109차와 같은 **무료 웹 계정**으로 뽑았다. 내장 브라우저 탭 `seed` → app.klingai.com/global/image/new, IMAGE 3.0. 설정 알약(왼쪽 아래) → Mode `1K SD` · Ratio `16:9` · Output `1` 이면 1장 1포인트. 프롬프트는 `.tiptap.ProseMirror` 에 `execCommand('insertText')` 로 넣는다.
- 결과 URL 은 오른쪽 피드의 `img.src` 에서 `:720x407.webp?...` 를 **떼면 원본 PNG(1360×768)** 가 나온다. 피드는 가상 스크롤이라 마우스 휠이 안 먹는다 → `document.querySelector('.virtual-history-stream').scrollTop = N` 으로 내려야 아래쪽(먼저 만든) 카드가 렌더된다.
- 무료 계정 워터마크는 우하단, 비율로 **x 0.868~1.0 · y 0.914~1.0 + 6 px 확장** 에 내용 인식 채우기를 걸면 깔끔히 지워진다(포토샵 ExtendScript는 IIFE 로 감싸이므로 `return` 필수).
- 남은 포인트 약 38.

- **그림 생성 경로를 Adobe Firefly 로 전환했다.** Kling API 는 여전히 잔액 0, Kling 웹 계정도 로그아웃 상태였다. Firefly 계정(songgmj@jette.co.kr / jette)은 **프리미엄 크레딧 190/4000, 다음 재설정 2026-09-22**.
- **단가**: Firefly Image 4/3 = 0(표준 무제한) · Firefly Image 5 = 10 · Gemini 3.1(Nano Banana 2) = 20 · Veo 3.1 영상 720p = 400. → 정지 그림은 사실상 무제한, **엔딩 MV 30초(8초x4 = 1600)는 9/22 재설정 이후에만 가능**.
- **화풍 테스트**: Image 4 무료로 8장(크레딧 0). 기본 프롬프트는 물감 튀김 때문에 v7 화풍과 안 붙고, 「얇은 잉크선 · 플랫한 수채 · 물감 튀김 금지 · 옆에서 본 무대식 구도 · 시각적 강도 낮춤」을 넣으면 108차 이벤트 그림에 근접한다.
