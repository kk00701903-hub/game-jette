# 컷씬 대본 표준 문체 (너와 나의 주파수) — v1 (2026-09-16, 사용자 지시)

컷씬 자막을 쓰거나 고칠 때 반드시 지킨다. v7 대본(`CUTSCENE_SCRIPTS_v7_읽기용.md`)이 기준본.

## 1. 원칙 — 겪은 일만 쓰고, 뜻은 쓰지 않는다
- 하늘이는 **본 것·들은 것·한 것**만 말한다. 그게 무슨 뜻인지, 왜 그런지는 독자가 알아내게 둔다. 독자가 아리송해야 감동이 온다.
- 반전(귀신·꼬마=아빠·아줌마=엄마) 전 구간에서 정체를 설명하는 문장은 한 줄도 두지 않는다. 힌트는 **행동과 물건**으로만(전단지를 건네는 손, 하트 계란말이, 해녀복 두 벌, 벽의 어른 우비, 꼬마의 눈물, 왼쪽 눈이 접히는 웃음).
- 회상에서 **엄마 얼굴만** 나오지 않는다(손·해녀복·숨소리만). 엄마의 젊은 얼굴은 게임 어디에도 안 나온다 — 현재의 아줌마와 이어지면 반전이 깨진다. 엄마 얼굴은 반전(CS7)에서 채워진다. 아빠와 어린 도윤 얼굴은 보여도 된다(아빠의 왼쪽 눈 접히는 웃음 = 꼬마의 웃음, 약한 떡밥).

## 2. 하지 않는 것 (실제로 걷어낸 예)
| 유형 | 지운 문장 | 대신 쓴 문장 |
|---|---|---|
| 감정을 이름으로 말하기 | 슬퍼 보이는 얼굴이네. | 웃지 않는 얼굴이었다. |
| 인과관계 해설 | 말 못 하는 사람의 숨소리는 크게 났다. | 소리 없는 사람의 숨비소리가 바다보다 컸다. |
| 「그래서 ~했던 거다」 | 그래서 얼굴만 안 보였던 거다. | (순서를 바꾸고 팩트만) 죽은 사람은 산 사람 얼굴부터 잊어버린다. 나는 살아 돌아온 게 아니었다. |
| 작가의 친절한 해설 | 엄마는 모르고 골랐다. 손이 기억한 거다. | 엄마는 모르는 애의 생일로 내 진짜 생일에 동그라미를 쳤다. |
| 정체를 흘리는 대사 | 「이거 벗으면 못 찾아.」 / 「누나는 안 추워.」 / 「봐. 다르게 볼 뿐이야.」 | 「엄마가 벗지 말랬어.」 / 「누나는 내 우비 반 줄게.」 / 「누나, 배고파.」 |
| 상태를 설명하는 서술 | 나는 있는데 없는 사람 같았다. / 모르는 사람한테 하는 인사였다. / 매일 모르는 사람처럼. | 나는 길가로 비켜섰다. / 「안녕하세요.」 / 매일 같은 자리, 같은 시간. |
| 이미 아는 정보 반복 | 엄마는 말을 못 한다. 듣지도 못한다. (CS3에서 이미 앎) | 아빠가 죽은 뒤, 우리 집은 완전히 소리가 사라졌다. |
| 설정을 보고서처럼 | 심장이 원래 약한 애였다. 나는 몰랐다. | 늘 입술이 파랗게 질려 있던 이유를 나는 그때 처음 알았다. (앞 컷의 「손이 떨리는 걸 나만 봤다」와 연결) |
| 관용구 | 말이 없어도 됐다. | 빗소리만으로 충분했다. |
| 아이가 자기 상태를 논리적으로 설명 | 「나도 아빠였던 거 잊어. 그냥 민재가 돼. 엄마 있는 여섯 살.」 | 「누나가 가면, 나도 아빠인 거 다 잊어버려. 그냥 여섯 살 민재가 돼.」 |
| 시각적이지 않은 설명 | 왜 돌아봤는지 자기도 모르는 얼굴로. | 낯선 사람을 보는 멍한 눈빛이었다. |
| 부정형으로 여운 끌기 | 못 한 말은 안 했다. 그냥 잡고 있었다. | 밀린 말 대신, 노래가 끝날 때까지 그냥 손을 잡고 있었다. |
| 철학·격언 | 「빌린 1년」「1년은 덤이야」류 | 쓰지 않는다. 달력에 적힌 약속 날짜를 그대로 쓴다. |

## 3. 문장
- 짧고 구체적으로. 한 컷에 한 가지 일. 「~였다」로 요약해서 닫는 문장은 장면당 두 개 이하.
- 감정을 직접 쓰는 건 장면당 한두 번만(무서웠다·외로웠다), 가장 무방비한 순간에.
- 「X가 아니라 Y」「그래서」「~는데도」 식의 정정·해설 문형은 쓰지 않는다.
- 회상은 짧게 끊지 않고 **롱컷**(한 장면을 이어지는 컷으로). 현재 장면은 짧은 컷.
- **한 컷 자막은 64자(두 줄) 이하.** 자막 띠를 넘으면 문장 단위로 컷을 나눈다. 따옴표 대사와 그 말을 한 사람은 같은 컷에, 「그래도」「그리고」로 시작하는 문장은 앞 문장과 같은 컷에 둔다.

## 4. 목소리
- 하늘(1인칭): 짧은 문장, 겪은 것만. 가끔 한 문장이 길어진다(마음이 달릴 때).
- 꼬마(민재): 재치 없음, 같은 말을 두 번 함(「그냥 알아.」「배고파.」「아무것도.」), 딴소리로 피함. 아는 걸 말로 흘리지 않는다.
- 도윤: 끝까지 맺는 말, 정중. 어릴 땐 「반은 네 거.」식 짧은 선언.
- 엄마(아줌마): 종이 글씨·손짓만. 글씨는 아주 짧고 삐뚤다(「밥 먹었어?」「많이 먹어.」).
- 아빠: 제주말, 웃는 소리. 「한 마리만 더 잡으민 뒈어, 하늘아.」
- 마을 사람: 사투리, 말이 옆으로 샌다(「몰라. 늙어서.」).
